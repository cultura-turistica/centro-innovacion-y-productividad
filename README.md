## 🎯 Propósito del Ecosistema

El **Centro de Innovación y Productividad (CIP)** es el brazo metodológico, tecnológico y formativo de **CULTURA T S.A.S.** (NIT: 901.144.063-0, Bogotá D.C.). 

Esta plataforma trasciende la digitalización pasiva de contenidos, consolidándose como un **entorno interactivo de apropiación social del conocimiento** que articula:
* **Academia y Cursos Dinámicos:** Módulos de formación territorial, simuladores interactivos, toma de decisiones y herramientas de costeo aplicadas a la realidad productiva.
* **Certificación Oficial con Sello Criptográfico:** Emisión de diplomas con firma digital y verificación pública e instantánea en `/verificar`.
* **Laboratorios de Analítica Geoespacial:** Mapas interactivos, modelos econométricos y cruce de datos oficiales de libre acceso (DANE, MinCIT, FONTUR).
* **Centro de Pensamiento y Sello Editorial:** Publicaciones científicas, artículos y memorias de investigación territorial.

## 🚀 Puesta en Marcha Local

De acuerdo con las reglas de arquitectura del proyecto, la gestión de dependencias se realiza exclusivamente con **`pnpm`**:

```bash
# 1. Clonar el repositorio
git clone https://github.com/cultura-t/repo-github.git

# 2. Instalar dependencias
pnpm install

# 3. Iniciar servidor local de desarrollo
pnpm run dev
```

El servidor estará disponible en `http://localhost:3000`.
